# LanQ · 蓝桥杯刷题仓库

按周次 + 知识点分类整理蓝桥杯 / 算法题练习代码。

GitHub：https://github.com/jiny2551-stack/LanQ

## 目录结构

```text
LanQ/
├── .vscode/          # 编辑器配置
├── Exttra/           # 额外资料、模板、笔记
├── Week1/ … Week8/   # 按周刷题
│   ├── <Topic>/      # 如 Stack、Queue、LinkedList
│   │   └── xxx.py    # 题号或题名命名
│   └── WeekN.md      # 本周总结 / 题单
└── README.md
```

## 命名约定

- 文件夹：知识点英文名（`Stack`、`Queue`、`LinkedList`…）
- 代码：优先题号（如 `3223.py`），也可中文题名（如 `重排列列表.py`）
- 每周一个 `WeekN.md` 记录进度与反思

## 使用方式

1. 在对应周的知识点文件夹下新建 `.py`
2. 更新该周 `WeekN.md` 勾选进度
3. `git add` → `commit` → `push`

加油，日拱一卒。
